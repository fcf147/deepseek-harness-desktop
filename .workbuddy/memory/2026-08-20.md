## 技术注意
- Git 操作必须经 wsl.exe -d FedoraLinux-44 -- bash -c "..."；Git Bash 下 /wsl$ 未挂载。Read/Edit 工具可直接用 //wsl$/FedoraLinux-44/...。
- bash heredoc 内写含反引号的内容会被当作命令替换，篡改 python 源；用 <<'PYEOF' 单引号定界符避免。含全角括号/反引号的行用 python re.sub(r"[^
]*") 整行替换最稳。
